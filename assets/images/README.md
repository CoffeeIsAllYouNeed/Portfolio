# Images & Logos

Drop your image files straight into this folder using the **exact filenames**
below. The site already links to these paths — as soon as a file with the
matching name appears here, it will show up on the live site automatically
(no code changes needed). If a file is missing, the site quietly falls back
to a placeholder, so nothing breaks in the meantime.

| Filename                        | Where it's used                     | Suggested size / shape        |
|----------------------------------|--------------------------------------|--------------------------------|
| `iit-roorkee-logo.png`           | Experience — IIT Roorkee circle logo | Square, at least 200×200px    |
| `iiser-pune-logo.png`            | Experience — IISER Pune circle logo  | Square, at least 200×200px    |
| `walmart-project.png`            | Projects — Walmart Data Analysis     | 16:10 landscape, e.g. 1200×750px |
| `queen-dta-project.png`          | Projects — QuEEN-DTA                 | 16:10 landscape, e.g. 1200×750px |
| `invisible-driver-project.png`   | Projects — Invisible Driver          | 16:10 landscape, e.g. 1200×750px |
| `ai-os-project.png`              | Projects — AI Operating System       | 16:10 landscape, e.g. 1200×750px |

### Notes
- Logos are shown inside circles and cropped to a square, so a centered,
  reasonably square logo (transparent background works best) looks cleanest.
- Project images are shown in a 16:10 landscape frame — a screenshot,
  diagram, or graphic related to the project works well.
- PNG or JPG both work. Keep individual files under ~1–2MB so the site
  stays fast to load.
- Want to add more images later (e.g. a profile photo)? Just drop the file
  in this folder and reference it from `index.html` / `style.css` with a
  path like `assets/images/your-file-name.png`.
